# DIVINE — Tier-One Digital Media Platform

Welcome to the DIVINE project repository.

## Instructions for Mr. K (Local Setup)

Follow these steps to run the DIVINE broadcasting platform locally on your laptop:

### Prerequisites
- [Node.js](https://nodejs.org/en/) (Version 18 or higher recommended)
- [Git](https://git-scm.com/) installed on your machine

### 1. Clone the Repository
Open your terminal and clone the repository:
```bash
git clone https://github.com/richhabits/divine.git
cd divine
```

### 2. Install Dependencies
Run the following command to install all necessary packages:
```bash
npm install
```

### 3. Run the Development Server
Start the local development server:
```bash
npm run dev
```

### 4. View the App
Open your web browser and navigate to:
[http://localhost:3000](http://localhost:3000)

---

**Note for Developers:**
This project is built using:
- **Next.js** (App Router)
- **React**
- **Tailwind CSS** (for styling and glassmorphic UI)
- **Framer Motion** (for smooth UI animations)

Make sure to pull the latest changes before starting work each time:
```bash
git pull origin main
```
